## GTA VI Optimization Guide

### 1. Configure Game Presets

Open:

Settings > Saved Data and Game/App Settings > Game Presets

Select Performance Mode as your preferred preset if desired.

This preference only affects games that support the relevant mode. It does not automatically unlock 60 FPS in GTA VI.

### 2. Configure Video Output

Navigate to:

Settings > Screen and Video > Video Output

Review:

- Resolution
- 120 Hz Output
- VRR
- HDR
- Video Output Information

Only enable options supported by your connected display.

### 3. Reduce Display Latency

For supported televisions:

1. Enable Game Mode.
2. Disable unnecessary image post-processing.
3. Use a suitable HDMI connection.
4. Verify the display is using its intended gaming input.
5. Check the television's firmware.

### 4. Improve Remote Play Stability

For an optimal Remote Play connection:

1. Connect the PS5 using Ethernet when practical.
2. Use a reliable network connection on the Windows PC.
3. Reduce competing network traffic.
4. Keep router firmware updated.
5. Test connection consistency.
6. Adjust Remote Play streaming quality when needed.

Sony recommends a connection of at least 15 Mbps for optimal Remote Play performance.

### 5. Maintain Your Console

Keep the PS5 and Grand Theft Auto VI updated.

Ensure sufficient ventilation and avoid enclosing the console in poorly ventilated spaces.

Follow Sony's official troubleshooting procedures for unexpected system behavior.

## Frequently Asked Questions

### Can this tool unlock 60 FPS in GTA 6?

No. There is no verified method in this workflow to remove GTA VI's console frame-rate limitations.

### Does the optimization require a jailbroken PS5?

No. The documented configuration procedures work with officially supported PlayStation features.

### Do I need to connect my PS5 to my computer?

A computer connection is required for the Remote Play workflow, but most console settings can also be configured directly on the PS5.

### Does Remote Play increase FPS?

No. Remote Play streams the console's video output to another device. Network optimization can improve streaming quality and responsiveness but cannot increase the game's internal rendering frame rate.

### Is GTA VI supported on PS5 Pro?

Yes. GTA VI supports both PlayStation 5 and PlayStation 5 Pro.
